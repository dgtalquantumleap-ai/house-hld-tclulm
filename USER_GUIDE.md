
# HouseHLD User Guide

Welcome to HouseHLD - your all-in-one household management app! This guide will help you get started and make the most of all features.

## Getting Started

### 1. Sign Up & Create Your Household

When you first open HouseHLD, you'll see our welcome screen with the marketing message:

> "Househld makes managing family life effortless. Create your household, coordinate calendars, plan meals, share tasks, and make decisions together — all in one place."

**Steps:**
1. Tap "Get Started" to create a new account
2. Enter your email, password, name, and select your role (Adult/Parent/Child/Roommate)
3. Verify your email (check your inbox for confirmation link)
4. **Create Your Household** (This step is mandatory!)
   - Enter household name (e.g., "Smith Family")
   - Add address (optional)
   - Upload household photo (optional)
   - Confirm your primary email

### 2. Invite Family Members

After creating your household, you can invite members:

**Option 1: Email Invitation**
- Enter email addresses of family members
- They'll receive an invitation email
- Track invitation status (Pending/Accepted)

**Option 2: Share Invite Code**
- Go to Household tab
- Tap the share button next to your invite code
- Share via text, email, or any messaging app

### 3. Connect Your Calendar (Optional)

You can connect Google Calendar or Apple iCloud:
- Tap on the calendar provider
- Authorize access via OAuth
- Your events will sync automatically
- You can skip this and set it up later

## Main Features

### 📅 Calendar

**View Modes:**
- **Daily**: See today's events
- **Weekly**: View the week ahead
- **Monthly**: Full month overview

**Adding Events:**
1. Tap the + button
2. Enter event title and description
3. Select date and time
4. Tap "Add Event"
5. Other household members will be notified

**Event Confirmation:**
- When someone adds an event, you'll see it with "Pending" status
- Tap "✓ Confirm" to accept
- Tap "✗ Decline" to reject
- Events show who created them

**Conflict Resolution:**
If two people edit the same event:
1. You'll see a conflict notification
2. Choose:
   - **Keep My Version**: Your changes stay
   - **Keep Partner's Version**: Accept their changes
   - **Merge Both**: Combine information

### ✅ Tasks & Chores

**Creating Tasks:**
1. Tap the + button
2. Enter task title and description
3. Task is added to the shared list

**Managing Tasks:**
- Tap a task to mark it complete
- Long press to delete (Adults/Parents only)
- View pending and completed tasks separately

**Task Status:**
- **Pending**: Not started
- **In Progress**: Being worked on
- **Completed**: Done! ✓

### 🛒 Shopping List

**Adding Items:**
1. Tap the + button
2. Enter item name
3. Add quantity (optional)
4. Add category (optional)

**Shopping:**
- Tap items to mark as purchased
- Purchased items move to "Purchased" section
- Tap again to unmark if needed

**Auto-Add from Meals:**
When you create a meal with ingredients, they're automatically added to the shopping list!

### 🍽️ Meal Planner

**Planning Meals:**
1. Tap the + button
2. Enter meal name (e.g., "Spaghetti Bolognese")
3. Add description (optional)
4. Select date and time
5. Add ingredients:
   - Enter ingredient name
   - Add quantity
   - Tap + to add more ingredients

**What Happens:**
- Meal is added to your calendar
- Ingredients are added to shopping list
- Household members are notified
- You can assign who's responsible for cooking

### 📊 Family Polls

**Creating Polls:**
1. Tap the + button
2. Enter poll title (e.g., "Where should we eat this weekend?")
3. Add description (optional)
4. Add at least 2 options
5. Tap "Create Poll"

**Voting:**
1. Tap on a poll to view it
2. Tap an option to vote
3. See real-time results with percentages
4. Add comments to discuss

**Poll Results:**
- Visual progress bars
- Vote counts
- Percentage breakdown
- Comment threads

### 👥 Household Management

**Viewing Members:**
- See all household members
- View roles (Admin/Member)
- See who's online

**Managing Members (Admins Only):**
- Remove members (tap X button)
- View member details
- Track pending invitations

**Household Info:**
- Creation date
- Total member count
- Your role
- Invite code

### 🔔 Notifications

**Notification Types:**
- 📋 Task assignments
- 📅 Event updates
- 🛒 Shopping list changes
- 📊 New polls
- 🍽️ Meal assignments
- 📧 Invitations

**Managing Notifications:**
1. Tap the bell icon on home screen
2. View all notifications
3. Tap ✓ to mark as read
4. Tap trash icon to delete
5. Tap "Mark All Read" to clear all

**Quick Actions:**
From the home screen, you can:
- Acknowledge notifications
- Mark tasks as done
- Respond to events

### ⚙️ Settings & Profile

**Profile Settings:**
- Update your name
- Change email
- Upload profile photo
- Update phone number

**Notification Preferences:**
- Toggle push notifications
- Toggle email notifications
- Control notification types:
  - Task notifications
  - Event notifications
  - Shopping notifications
  - Poll notifications
  - Meal notifications

**Privacy Settings:**
- Show/hide personal calendar events
- Manage calendar connections

1. **Coordinate Schedules:**

2. **Share Responsibilities:**

## Roles & Permissions

### Admin
- Full access to all features
- Can remove members
- Can delete any content
- Manages household settings

### Adult/Parent
- Can create and manage all content
- Can assign tasks
- Can delete own content
- Cannot remove members (unless admin)

### Child
- Can view all content
- Can mark tasks complete
- Can add shopping items
- Cannot delete content
- Cannot remove members

### Roommate
- Similar to Adult role
- Full collaboration access
- Can manage shared content

## Troubleshooting

### Can't Sign In?
- Check your email is verified
- Try "Forgot Password"
- Ensure you're using the correct email

### Not Receiving Notifications?
- Check notification settings in app
- Check device notification permissions
- Ensure app is updated

### Calendar Not Syncing?
- Reconnect your calendar
- Check OAuth permissions
- Try disconnecting and reconnecting

### Invite Code Not Working?
- Ensure code is entered correctly
- Check if invitation is still pending
- Contact household admin
